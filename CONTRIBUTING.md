# Contributing to Pilot

Thank you for your interest in the project! Issues and pull requests are
welcome.

## Issues

- Use **Bug report** for defects and **Feature request** for ideas.
- Search existing issues first; add details, logs, and reproduction steps.
- One problem per issue.

## Pull requests

- Fork the repository and open a PR against `main`.
- Keep PRs focused: one change per PR.
- Code must pass CI (hassfest, tests, lint) before review.
- Follow the existing style; write tests for new behavior.

## Merge policy

**Only the project owner merges into `main`.** Contributions are reviewed and
merged by the owner. Opening a PR does not guarantee merge; large changes are
best discussed in an issue first.
