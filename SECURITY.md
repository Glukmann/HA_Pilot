# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report them privately to the repository owner via GitHub
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities)
(see the "Report a vulnerability" button on the repository's Security tab), or
via a direct message if you know the owner.

## Scope notes

Pilot is designed to run fully local. Never post tokens, API keys, or personal
home data (addresses, device IDs of a real household) in issues or PRs.
