# Changelog

## 0.4.5

- **Автоматическое обнаружение**: аддон сам сообщает Home Assistant о себе при
  запуске — интеграция появляется в «Обнаруженные», достаточно нажать
  «Подтвердить». Вводить адрес и порт больше не нужно.
- Если аддон запущен вне Supervisor (автономный режим), объявление молча
  пропускается — ручная настройка по адресу по-прежнему работает.

## 0.4.4

- К сущностям в витрине данных теперь подписываются комнаты (из областей HA):
  карта дома сгруппирована по комнатам, агент рассуждает «по-комнатно».

## 0.4.3

- **Карта дома теперь обновляется сама**: интеграция передаёт изменения
  состояний в рантайм напрямую (быстро и без участия токенов доступа).
- Убрана ручная настройка токена Home Assistant для витрины.

## 0.4.2

- Исправлен запуск контейнера аддона (рабочая директория сборки образа).

## 0.4.1

- Исправлен запуск скрипта старта (права на исполнение).

## 0.4.0

- Первый публичный MVP: рантайм агента с HTTP API, контур доверия
  (очередь подтверждений, бюджет, журнал), зеркало состояния дома,
  установка через магазин дополнений.
