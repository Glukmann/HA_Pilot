# Доменные знания дома

Заполни разделы своими entity_id и привычками — супервизор учитывает их при
решениях. Заглушки вида `<...>` замени реальными значениями; неподходящие
разделы удали.

## Отопление

- Основной обогрев: `<climate entity_id теплового насоса>` — летом охлаждение,
  зимой основной эффективный обогрев дома.
- Локальный догрев спальни: `<обогреватель entity_id>`.
- Правило «тепло в доме»: приоритет тепловому насосу, обогреватель — догрев,
  не дублирует его.

## Ванная

- Нагрев (PTC): `<switch нагрева>`; целевая температура — `<input_number уставки>`,
  комфортный диапазон 25–35°C.
- Вытяжка: `<fan entity_id>`; после душа — по времени (влажность не измеряется).
- «Вытяжка забыта» — флаг по времени работы, не по влажности.

## Свет и медиа

- Сценарий «кино»: свет в зоне TV гасим/приглушаем при включённом
  медиаплеере (`<media_player entity_id>` по комнатам: кабинет, спальня,
  гостиная).

## Двери и ворота

- Калитка/ворота — импульсные реле: ON дольше 10 минут = застревание (флаг
  `gate_stuck`), действие — только через очередь доверия.
