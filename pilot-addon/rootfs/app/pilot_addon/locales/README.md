# Локали Пилота

`chat.csv` — весь пользовательский текст чата (детерминированный fallback и
LLM-промпты): один ключ на строку, один язык на колонку. Репозиторий держит
`ru` и `en` как образец; новый язык = **новая колонка**.

## Как добавить язык

1. Добавьте колонку с двухбуквенным кодом языка (ISO 639-1: `de`, `fr`, `uk`…).
2. Переведите **все** строки. Проверка полноты — тест `test_locale_completeness`:
   язык «включается», только когда заполнен `prompt.system`, но CI требует
   заполнения всех ключей.
3. `{placeholders}` в фигурных скобках и `|` (списки-синонимы) сохраняйте как есть.
4. `\n` в ячейке — перенос строки (так хранятся многострочные промпты).
5. Регулярные выражения (`fallback.setpoint.re`) — перепишите под грамматику
   языка, **имена групп `(?P<verb>…)` и `(?P<value>…)` и `(?P<area>…)` сохраните**.

Язык активируется автоматически: HA присылает код языка пользователя с каждым
запросом, дефолт можно задать в конфиге аддона (`config/set`, секция `chat`,
поле `language`).

Строки в коде не хардкодить — только через ключи из этого файла.
